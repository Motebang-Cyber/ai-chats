AI Chats - System Architecture

1)Architecture Overview
The initial application will begin as a modular monolith so that the core functionality can be developed and
understood before being separated into independent services.

The long-term architecture will evolve toward a distributed, service-oriented architecture using containers, 
messaging, orchestration, cloud, infrastructure, monitoring and automated deployement.

2)Architecture principle
Build simple first, understand it, then introduce complexity for a reason.

Ai charts is intended to demostrate not only that the application works, but that its infrastructure can be built, deployed,
monitored, broken, diagnosed, recovered, and continuously improved.
